## 📌 Overview

This project is a high-fidelity front-end clone of Amazon.com. The primary focus of this build is on crafting a clean, highly functional user interface with complex responsive layouts, state management, and an aesthetic design approach. It serves as a showcase of advanced UI/UX development and modern component-based architecture.

## ✨ Features

* **Responsive Design:** Fluid layouts that adapt seamlessly from mobile to wide desktop screens.
* **Header & Navigation:** Exact replica of the Amazon top navigation bar, including the search input, category dropdown, and hover-state mega menus.
* **Product Carousel:** Smooth sliding image banners for the homepage hero section.
* **Product Grid:** Dynamic grid layouts mapping over mock product data.
* **Shopping Cart UI:** State-driven cart implementation with subtotal calculations.
* **Checkout Simulation:** A cleanly designed mock checkout and payment processing page.
* **Authentication UI:** Replicated Amazon login and registration screens.

## 🛠️ Tech Stack

* **Framework:** [Next.js](https://nextjs.org/) / React
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Icons:** Heroicons / Material UI Icons
* **State Management:** Redux Toolkit / React Context API
